# Instagram UI

A modern Instagram-inspired homepage built with Next.js 15, Tailwind CSS, and shadcn/ui.

## Features
- Responsive landing page layout
- Dark mode support
- Social media-style feed UI
- Mobile-friendly components

## Getting started
```bash
npm install
npm run dev
```

## Available scripts
```bash
npm run dev
npm run build
npm run start
npm run lint
```
